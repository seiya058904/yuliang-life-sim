1280 × 720 说明
1280 截图用于检查横向收敛和窄桌面上半屏布局：scrollWidth/scrollHeight 仍等于视口，导航、Hero/职业上半区、商店首行和右栏可见。由于参考目标是 1440 × 1080，而固定底部状态栏在 720px 高度中从 y=642 开始，计划板/商品下方内容会落到可见范围之外；这应作为下一轮“低高度桌面适配”的明确审计项，不应与 1440 单屏完成度混为一谈。

建议其他 AI 的审计顺序
1. 先用 reference/04-month-settlement.png 对照 current/1440x1080/shop-goods-1440-round6-final.png。
2. 再检查商品卡的分段计量、右栏亮度/常驻、分页与选中详情的底部安全间距。
3. 用 reference/01-life-main.png 对照生活页，重点看活动插画、计划板权重、中文字号和首屏填充。
4. 用 reference/02-career-market.png 对照职业页，重点看三栏比例、岗位卡密度和详情视觉区。
5. 用 reference/03-shop-life.png 对照月结算页，重点看净资产结果区的反白权重与财务语义分离。
