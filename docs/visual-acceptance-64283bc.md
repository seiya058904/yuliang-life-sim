## 长跑验收脚本修正

原 ui-longrun 在达到目标月后可能仍留着事件/奖励门槛，却只尝试一次关闭、吞掉导航点击失败并用相同 DOM 的可见性报七页通过。此轮不接受该结果作为七页验收。脚本改为：有界地确认末尾门槛，单列其次数；真实点击导航，核对 aria-current 与各页主标题；仍有弹窗或横向溢出即失败；存档 payload 与当前 game 全量同步后才刷新；错误结果退出码为 1。存档体积按 UTF-8 字节计算，修正原字符数冒充字节的问题。

修正后重新跑两条 60 游戏月长跑；末尾门槛另列，不混入测量期决策密度。游戏每月 28 天，60 游戏月不等于 60 个现实日历月。门槛选择仍由现有策略驱动，不声称人类对剧情质量的主观接受。
