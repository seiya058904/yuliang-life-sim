# 《余量》桌面 UI 收敛规格

## 目标

在不改变游戏规则、存档兼容性、官方内容 ID 或财务账本语义的前提下，让成品桌面界面与四张参考图在 1448×1086 视口下高度接近：黑白 1-bit 像素控制台、明确的白色反相重点区、强标题层级、密集但可读的网格，以及持续可见的时间/现金/净资产/HUD。

## 参考图映射

- `01-life-main.png`：生活主控制台，默认入口。
- `02-career-market.png`：职业招聘市场。
- `03-shop-life.png`：月结算仪式（文件名与画面内容相反）。
- `04-month-settlement.png`：商店目录（文件名与画面内容相反）。

## 设计约束

- 参考图是视觉真值；当前源码、测试、引擎和内容合同是行为真值。
- 保持桌面优先与横屏逻辑；不新增竖屏设计目标。
- 不使用截图作背景、渐变、圆角 SaaS 卡片或装饰性 emoji；保留真实按钮、可访问名称和真实游戏数据。
- 所有展示文本通过内容/显示层解析，不能把 canonical ID 写到 UI 文案中；canonical ID 本身不改。
- 月结算继续展示收入、消费、资产配置、资产变现、已实现收益和净资产变化的区别；确认按钮只推进既有暂停节点。
- 新游戏默认打开生活页；职业页由主导航显式进入。

## 验收标准

- 1448×1086 桌面首屏能辨认出参考图的四个主构图：生活 Hero + 白色预测区、职业三栏、商店目录 + 白色工具/详情区、月结大框 + 净资产焦点。
- 顶栏和底部角色状态条在四个核心页保持一致，时间推进/暂停控件可操作且不会被 CSS 隐藏。
- 财富、社交、城市、我的页面使用同一套像素面板/反相重点/密集列表语言，并补足可识别的视觉锚点。
- 现有单元测试、内容校验、模拟脚本、构建和 Playwright E2E 通过；浏览器流程实际检查默认入口、四个核心页及至少一个时间/弹层交互。
